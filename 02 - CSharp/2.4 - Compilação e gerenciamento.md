**Curso: Fundamentos do C#**

**📖 Conceito de compilação e gerenciamento:**  

```
A Microsoft oferece suporte a várias linguagens de programação dentro de seu ecossistema,  
como **VB.NET**, **F#** e até mesmo **COBOL.NET**. Todas essas linguagens compartilham  
um suporte contínuo para manutenção de código, correção de bugs e aprimoramentos.  

O ecossistema de desenvolvimento da Microsoft foi projetado para oferecer suporte  
a **múltiplas linguagens**, permitindo flexibilidade para os desenvolvedores.  
Ter um gerenciador separado para cada linguagem tornaria o processo excessivamente complexo.  
```
**📖 IL - Linguagem Intermediária**  

```
Quando um código em **C#** é compilado, ele não se transforma diretamente em binário.  
Primeiro, ele é traduzido para uma **Linguagem Intermediária (IL)**, um formato comum  
a todas as linguagens suportadas pela Microsoft, como VB.NET e F#.  

No processo final, a IL é convertida em código binário executável pelo **Common Language Runtime (CLR)**.  
Esse modelo unificado permite que diferentes linguagens coexistam no mesmo projeto,  
com todos os arquivos sendo traduzidos para IL antes de serem compilados para o binário. 
```
