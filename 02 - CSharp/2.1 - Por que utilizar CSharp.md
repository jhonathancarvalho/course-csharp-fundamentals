**Curso: Fundamentos do C#**

**📖 Por que utilizar C#**  

C# (CSharp) é uma linguagem de programação moderna, fortemente tipada, compilada e gerenciada, desenvolvida por Anders Hejlsberg e mantida pela Microsoft.

**📖 Motivos para escolher C#:**

**Completa e confiável:**

Alta maturidade, graças à constante evolução.
Uma escolha estável e amplamente utilizada na indústria de software.

**Mercado em expansão:**

Forte presença em grandes empresas.
Ampla demanda para desenvolvimento de sistemas corporativos e soluções em nuvem.

**Comunidade ativa:**

Vibrante e global, com grupos, fóruns e eventos que promovem a troca de conhecimento.
Facilidade em encontrar suporte e boas práticas.

**Aplicabilidade versátil:**

Desenvolvimento web (ASP.NET).
Aplicações móveis (via Xamarin ou MAUI).
Software desktop (Windows Forms, WPF).
Jogos, especialmente com a engine Unity.
Soluções em nuvem (Azure).

**Resumo:**

C# é ideal para quem busca uma linguagem poderosa, flexível e amplamente suportada, com aplicabilidade em diversos setores da tecnologia.

**Exemplo em C#:**

```C#
using System;

class Programa
{
    static void Main()
    {
        Console.WriteLine("Bem-vindo ao mundo C#!");
    }
}
```
