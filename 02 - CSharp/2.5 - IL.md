**Curso: Fundamentos do C#**

**📖 IL - Linguagem Intermediária**  **  
```
- Apesar de cada linguagem possuir seu próprio processo de compilação,  
  o gerenciamento do código no ambiente .NET é uniforme para todas.

- É possível combinar várias linguagens em um único projeto, mas cada arquivo  
  deve ser escrito em apenas uma linguagem.
 
- O **resultado final da compilação para IL** é consistente, independentemente  
  da linguagem utilizada.  
```

**📖 Conceito de Just-In-Time**  

```
- **JIT (Just-In-Time)** é o processo que converte a **IL** em código binário,  
  tornando-o executável diretamente pelo processador.
 
- Esse processo ocorre em tempo de execução, permitindo otimizações dinâmicas  
  baseadas no ambiente onde o código está sendo executado.  
```
