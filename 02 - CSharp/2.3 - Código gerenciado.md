**Curso: Fundamentos do C#** 

**📖 Conceito de Código Gerenciado**

C# é uma linguagem de código gerenciado, cuja execução depende de um gerenciador chamado Runtime, ou CLR (Common Language Runtime - Ambiente de Execução de Linguagem Comum).

Como funciona o código gerenciado?
O CLR gerencia automaticamente a memória, alocando e liberando recursos de forma eficiente.
Isso elimina a necessidade de manipulação manual de memória, como ocorre em linguagens como C/C++.

**📖 Benefícios do código gerenciado:**

**Segurança de memória:**

Reduz problemas como violação de memória, comuns em linguagens não gerenciadas.
Evita falhas graves, como a "tela azul" do Windows, causada por acessos incorretos à memória.

**Desenvolvimento confiável:**

Desenvolvedores interagem menos diretamente com recursos de hardware.
O processo é mais seguro e confiável, com menor risco de erros críticos.

**📖 Diferença para código não gerenciado:**

**Código gerenciado (C#):**

Executado pelo CLR.
Focado na segurança e na automação de tarefas complexas, como gerenciamento de memória.
Código não gerenciado (C/C++):

Exige alocação e liberação manual de memória.
Maior risco de erros, mas com controle direto do hardware.

**Resumo:**

O uso de código gerenciado em C# simplifica o desenvolvimento, melhora a segurança e reduz falhas, permitindo que o foco seja na criação de soluções robustas.

**Exemplo de código simples em C#:**

```C#
using System;

class Programa
{
    static void Main()
    {
        // O CLR gerencia a memória para criar e descartar este objeto
        string mensagem = "C# é uma linguagem de código gerenciado!";
        Console.WriteLine(mensagem);
    }
}
```
