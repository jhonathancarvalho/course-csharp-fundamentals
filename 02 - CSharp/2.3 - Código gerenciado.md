**Curso:** Fundamentos do C# 

**📖 Conceito de código gerenciado:**  
```
C# é uma linguagem de **código gerenciado**, o que significa que sua execução  
depende de um gerenciador, no caso o **Runtime**, também chamado de **CLR**  
(*Common Language Runtime* - Ambiente de Execução de Linguagem Comum).  

Diferentemente de linguagens como **C/C++**, onde a alocação de memória é feita  
manualmente, em C# o CLR gerencia automaticamente a memória, alocando e  
liberando recursos de forma eficiente.  

Isso reduz significativamente problemas como **violação de memória**, que em  
linguagens não gerenciadas podem causar falhas graves, como a famosa "tela azul"  
do Windows, resultado de um programa acessando áreas de memória reservadas.  

Graças ao CLR, os desenvolvedores interagem menos diretamente com os recursos  
de hardware, tornando o processo de desenvolvimento mais seguro e confiável.
```
