**Curso: Fundamentos do C#**

**📖 C# como primeira linguagem**  

```
- C# não é a linguagem mais simples do mercado, mas oferece uma base sólida para desenvolvimento.  

- A linguagem é fortemente focada em **Programação Orientada a Objetos (OOP)**, que é um dos pilares da
programação moderna, embora também suporte paradigmas como a programação funcional.  

- Escolher um caminho **fácil no início** pode levar a dificuldades futuras, enquanto dominar fundamentos sólidos,
como OOP, facilita o aprendizado de novas tecnologias e paradigmas.  

- Quanto mais tempo você investir em aprender o básico, mais preparado estará para enfrentar desafios e adotar novas abordagens.  

- Consolidar o básico é essencial. Sem essa base, aprender conceitos avançados ou trabalhar em situações fora do
seu cotidiano pode se tornar um grande obstáculo.  

- Se você sente **dificuldade para codificar algo novo ou para se adaptar a mudanças**, é um sinal claro de
que é hora de revisitar e fortalecer seus fundamentos.  
```
