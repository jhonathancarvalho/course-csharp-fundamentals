[[5.0 - Programação com CSharp]]

**Curso:** Fundamentos do C# 


Podemos segmentar nosso programa funções. Também conhecidos como métodos.

O main é um exemplo de método.
Possui um retorno um nome e parâmetros.
Esta composição e camada de assinatura.

Começam sempre com maiúscula.

Class Program
{
	static void Main (string[] args)
		{
		MeuMetodo();
		}
	static void MeuMetodo()
	{
		Console.WriteLine("C# é legal");
	}
}
