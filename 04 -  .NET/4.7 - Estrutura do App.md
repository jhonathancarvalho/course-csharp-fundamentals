**Curso: Fundamentos do C#**

**📖 Estrutura do Console:**  

Ao criar um projeto **Console Application** no .NET, alguns arquivos e estruturas padrão são gerados automaticamente. 

A seguir, destacamos os principais:

---

**📖 1. Arquivo `.csproj`**  

- **Formato:** XML.  
- **Função:** Define as configurações e metadados do projeto.  
- **Características:**  
  - Contém informações como o **framework alvo**, **dependências**, e **configurações de build**.  
  - Essencial para que o .NET entenda como compilar e executar o projeto.  

> Exemplo de trecho de um arquivo `.csproj`:  
```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net6.0</TargetFramework>
  </PropertyGroup>
</Project>
```
---

**📖 2. Arquivo Program.cs**

**Função:** É o ponto de entrada do programa (arquivo principal).
**Característica principal:** Contém o método Main, que é executado primeiro quando a aplicação é iniciada.

```C#
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Olá, mundo!");
    }
}
```
