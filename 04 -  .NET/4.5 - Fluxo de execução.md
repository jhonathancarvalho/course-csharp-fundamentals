**📖 Fluxo de Execução no .NET CLI** 

1. **`dotnet restore`:**  
   - Busca e instala todos os pacotes e dependências necessários para a execução do projeto.  
   - Deve ser executado antes de compilar um projeto, especialmente se houve alterações no arquivo `*.csproj`.  

2. **`dotnet build`:**  
   - Compila o código-fonte, gerando os arquivos binários da aplicação.  
   - Cria uma estrutura organizada na pasta `bin/` do projeto, pronta para execução ou publicação.  

3. **`dotnet clean`:**  
   - Remove os arquivos gerados durante o processo de build.  
   - Útil para liberar espaço ou garantir que um novo build seja executado a partir de um estado limpo.  

4. **`dotnet run`:**  
   - Compila e executa a aplicação em um único comando.  
   - Ideal para testar o projeto durante o desenvolvimento, sem a necessidade de etapas manuais.  

---

### **Exemplo de Fluxo Completo:**  

1. **Restaurar pacotes e dependências:**  
```bash
 dotnet restore
```
2. **Compilar a aplicação:**
```bash
dotnet build
```
3. **Executar a aplicação:**
```bash
dotnet run
```
4. **Limpar o projeto (opcional):**
```bash
dotnet clean
```
