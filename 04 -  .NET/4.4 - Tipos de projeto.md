**Curso: Fundamentos do C#** 

**📖 Tipos de Projetos:**

1. **Class Library:**
   
   - O resultado final é uma DLL.  
   - Não possui interface de usuário, sendo usada para armazenar e compartilhar lógica.  

3. **Console Application:**
   
   - O resultado final é uma aplicação que roda no terminal.  
   - Permite interação com o usuário através de inputs e outputs no console.  

5. **Projeto Web:**
   
   - Projetos voltados para desenvolvimento web, como:  
   - **ASP.NET Web:** para aplicações baseadas em páginas web.  
   - **ASP.NET MVC:** para aplicações com o padrão de arquitetura Model-View-Controller.  
   - **ASP.NET Web API:** para criação de APIs RESTful.  

7. **Projeto de Testes:**
   
   - Projetos dedicados à escrita de testes automatizados, como os baseados em **Microsoft Tests (MSTest)**.

---

**📖 Criação de Novos Projetos com CLI**  

**Comandos para criar diferentes tipos de projetos:**  

- `dotnet new console` — Cria um projeto de aplicação de console.  
- `dotnet new classlib` — Cria uma biblioteca de classes.  
- `dotnet new mvc` — Cria um projeto ASP.NET MVC.  
- `dotnet new webapi` — Cria uma API com ASP.NET.  
- `dotnet new mstest` — Cria um projeto para testes automatizados.

**Exemplo:**  

- Para criar um projeto de console em uma pasta específica:
  
```bash
dotnet new console -o MeuApp
```
