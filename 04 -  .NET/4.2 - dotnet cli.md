
[[4.0 - .NET]]

**Curso:** Fundamentos do C# 

**📖 Conceito de CLI::**  

```
- CLI significa **Command Line Interface** (Interface de Linha de Comando).
 
- É utilizada para executar comandos diretamente no terminal.

- No caso do .NET, os comandos são definidos pelo prefixo `dotnet`,
permitindo gerenciar projetos, verificar versões, entre outros.
```

**📖 Comandos úteis**

```
1. **`dotnet --version`**  
   Exibe a versão instalada do .NET SDK.  

2. **`clear`**  
   Limpa o terminal, deixando-o organizado para novos comandos.  

3. **`dotnet --list-sdks`**  
   Lista todos os SDKs instalados na máquina.  

4. **`dotnet --list-runtimes`**  
   Lista todas as runtimes instaladas.  

5. **`dotnet help`**  
   Mostra uma lista completa de comandos disponíveis no CLI .NET.  

```
