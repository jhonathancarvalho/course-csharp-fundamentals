**📖 Variáveis de Ambiente:**  

As variáveis de ambiente permitem configurar diferentes cenários para o funcionamento das aplicações, facilitando o gerenciamento de **configurações específicas** para cada ambiente.  

---

**📖 Principais Ambientes**:  

- **Desenvolvimento (Development):**
- 
  - Ambiente usado para criar e testar funcionalidades.  
  - Geralmente, possui configurações simplificadas e sem preocupação com segurança.
     
- **Homologação (Staging):**
- 
  - Espelha o ambiente de produção para testes finais.  
  - Utilizado para validar a aplicação antes de liberar para o público.
    
- **Produção (Production):**
- 
  - Ambiente final onde a aplicação será disponibilizada para os usuários.  
  - Requer alto desempenho e configurações de segurança.  

---

**📖 Configurações por Ambiente**  

Cada ambiente pode ter configurações específicas, como:  
- **Chaves de acesso externo** (APIs, serviços de terceiros).  
- **Conexões com bancos de dados** (endereços e credenciais diferentes).  
- **Logs e diagnósticos** (detalhados em desenvolvimento e reduzidos em produção).  

---

**📖 Definindo o Ambiente no .NET**  

O .NET permite especificar o ambiente de execução ao iniciar a aplicação:  

- **Comando para Desenvolvimento:**  
```bash
dotnet run --environment=Development
```
- **Comando para Produção:**
```bash
dotnet run --environment=Production
```
