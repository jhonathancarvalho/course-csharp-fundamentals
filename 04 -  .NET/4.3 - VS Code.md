---

**📖 Conceito:**


- **Visual Studio Code (VS Code):**  
  Um editor de código leve e completo, ideal para máquinas com configurações mais modestas.  

- **Visual Studio Community:**  
  Uma IDE robusta com diversos recursos adicionais, indicada para projetos mais complexos, mas que exige maior capacidade da máquina.  

---

**📖 Principais extensões:**



1. **Extensão do C#:**  
   Essencial para trabalhar com projetos em C#.  

2. **Extensões de Temas:**  
   Personalize a aparência do editor com temas populares, como:  
   - One Dark Pro  
   - Minimal  
   - Dracula Theme  

3. **Extensão de Ícones:**  
   Adicione ícones ao explorador de arquivos para facilitar a organização e identificação:  
   - VSIcons
