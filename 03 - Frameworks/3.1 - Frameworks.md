[[3.0 - Frameworks]]

**Curso:** Fundamentos do C# 

**📖 Conceito de Framework:**  

```
- Um **Framework** é uma estrutura que serve como base para desenvolver aplicações,  
  fornecendo um conjunto de bibliotecas e ferramentas prontas para uso.

- Ele facilita o desenvolvimento ao evitar que precisemos criar tudo do zero,  
  oferecendo soluções para tarefas comuns.

- O conceito de framework é amplamente utilizado em várias tecnologias.  
  Neste curso, exploraremos o **.NET**, o framework da Microsoft. 
```

**📖 Conceito do .NET Framework:** 

```
- O **.NET Framework** oferece uma coleção de recursos e funcionalidades prontas,  
  como operações de leitura e escrita de arquivos, manipulação de banco de dados  
  e comunicação em rede, para simplificar o desenvolvimento de software.

- Ele foi projetado para poupar tempo e garantir confiabilidade, com componentes  
  validados e testados.

- Usar um framework evita reinventar a roda, tornando o desenvolvimento mais eficiente  
  e confiável.  
```
