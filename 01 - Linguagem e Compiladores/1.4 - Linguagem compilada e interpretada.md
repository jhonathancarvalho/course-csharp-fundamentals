
[[1.0 - Linguagens e Compiladores]]

**Curso: Fundamentos do C#** 

**📖 Conceito de Linguagem Compilada:**

 ```
Há um processo de **compilação**, que converte o código-fonte (texto escrito pelo programador)  
em código de máquina (binário) antes da execução. Esse código é otimizado pelo compilador,  
tornando a execução mais eficiente, mas exige um passo prévio para gerar o executável.
 
Exemplo: **C#** utiliza o compilador para gerar código intermediário (IL), que é executado pela  
**Common Language Runtime (CLR)**.
```


**📖 Conceito de Linguagem Interpretada:**

```
São linguagens cujo código-fonte é lido e executado por um **intérprete** diretamente, sem  
necessidade de compilação prévia. Esse processo acontece durante a execução do programa,  
o que pode reduzir o desempenho, mas facilita alterações dinâmicas.

Exemplo: **JavaScript**, onde os navegadores modernos interpretam e executam o código  
diretamente.
```
