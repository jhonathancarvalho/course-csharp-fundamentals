
[[1.0 - Linguagens e Compiladores]]

**Curso:** Fundamentos do C#  

**📖 Conceito:**

```
Quando enviamos uma instrução ao computador, estamos operando em **nível de máquina**, onde os comandos são representados
 em **código binário** diretamente compreendido pelo processador.

As linguagens de **baixo nível** trabalham mais próximas ao hardware, utilizando instruções detalhadas e específicas, como
o Assembly, que requer controle direto de registradores e memória. Quanto mais detalhada e próxima do hardware a instrução,  
mais "baixo" é o nível da linguagem.

Já as linguagens de **alto nível**, como **C#** e **Java**, abstraem a complexidade do hardware, permitindo que o programador
se concentre em resolver problemas de forma  mais intuitiva e legível, com menos atenção aos detalhes técnicos do sistema.

```



**📖 Exemplo de linguagem de baixo nível (Assembly):**

```Assembly
section .data
    msg db 'Hello, World!', 0    ; Define uma mensagem

section .text
    global _start

_start:
    mov rax, 1                  ; Chamada de sistema: write
    mov rdi, 1                  ; File descriptor: stdout
    mov rsi, msg                ; Endereço da mensagem
    mov rdx, 13                 ; Tamanho da mensagem
    syscall                     ; Chama o sistema
    mov rax, 60                 ; Chamada de sistema: exit
    xor rdi, rdi                ; Código de saída: 0
    syscall 
```

```
Esse código em Assembly escreve "Hello, World!" no console diretamente utilizando instruções específicas para o processador.
```

**📖 Exemplo de código em C#, uma linguagem de alto nível:**

```C#
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}
```

```
Esse código em C# realiza a mesma função, mas abstrai os detalhes de como a mensagem é enviada ao console, utilizando bibliotecas
e comandos mais próximos à linguagem humana.
```
