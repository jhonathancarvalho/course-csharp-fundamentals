
[[1.0 - Linguagem e Compiladores]]

**Curso: Fundamentos do C#**  

**📖 Conceito de Tipagem de Dados:**

Linguagens fortemente tipadas exigem que o tipo de dado de cada variável seja explicitamente declarado durante o desenvolvimento.

Vantagens:
Maior segurança de tipos.
Detecção precoce de erros.
Melhor otimização durante a execução.
Por outro lado, isso pode reduzir a flexibilidade ao escrever o código, mas compensa com maior robustez no resultado final.

**📖 Tipo de Dado:**

Um tipo de dado define a natureza e o formato da informação armazenada em uma variável.

Ele especifica o que o valor pode representar, como:
Números inteiros (e.g., int).
Caractere único (e.g., char).
Cadeias de texto (e.g., string).
Estruturas mais complexas, como listas e classes.

**Exemplo em C#:**

```c#
int idade = 25;       // Número inteiro  
string nome = "Ana";  // Cadeia de texto (string)  
char inicial = 'A';   // Caractere único  
double altura = 1.75; // Número de ponto flutuante
```

Essa especificação permite que o compilador entenda como tratar os dados e evite erros inesperados durante a execução do programa.
