
[[1.0 - Linguagens e Compiladores]]

**Curso:** Fundamentos do C#  

**📖 Conceito:**

```
Uma linguagem de programação é um sistema formal composto por regras e sintaxes utilizadas para criar instruções que podem ser interpretadas ou compiladas por computadores. Essas linguagens permitem a comunicação entre humanos e máquinas, possibilitando o desenvolvimento de software, desde sistemas operacionais até aplicações web. Elas possuem semântica e sintaxe próprias e são classificadas em diferentes níveis, como alto nível (próximas à linguagem humana) e baixo nível (mais próximas do código de máquina).
```

```
Podemos ainda dizer que a linguagem de programação é a forma como nos comunicamos com a máquina.
Escrevemos uma linguagem que é traduzida para uma linguagem binária que será lida por um computador através do processo de "tradução", conhecido como complicação.
```
