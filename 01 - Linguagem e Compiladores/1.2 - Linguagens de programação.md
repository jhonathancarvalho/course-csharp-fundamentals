**Curso: Fundamentos do C#**  

**📖 Conceito de Linguagem de Programação:**

- Uma **linguagem de programação** é um sistema formal que define regras e sintaxes  
  utilizadas para criar instruções compreensíveis por computadores.

- Ela serve como uma ponte entre humanos e máquinas, possibilitando o desenvolvimento  
  de diversos tipos de software, como sistemas operacionais, aplicativos móveis e web.

---

**📖 Características Principais:**

1. **Semântica:** Refere-se ao significado das instruções.
2. **Sintaxe:** Determina a estrutura e forma correta das instruções.

---

**📖 Classificação das Linguagens:**

- **Alto nível:** Mais próximas da linguagem humana, como C#, Python e Java.  
- **Baixo nível:** Mais próximas do funcionamento do hardware, como Assembly e código de máquina.

---

**📖 Explicação Simplificada:**

- A linguagem de programação é como **nos comunicamos com o computador**.  
- Escrevemos instruções que são traduzidas para linguagem binária (entendida pela máquina).  
- Esse processo de tradução ocorre por meio da **compilação** ou **interpretação**.

Exemplo:  
Um programa em C# é compilado para código intermediário (IL),  
que é posteriormente convertido para o formato binário executável pelo computador.
