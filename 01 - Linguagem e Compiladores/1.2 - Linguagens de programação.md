
[[1.0 - Linguagens e Compiladores]]

**Curso:** Fundamentos do C#  

**📖 Conceito de linguagem de programação:**

```
- Uma **linguagem de programação** é um sistema formal que define regras e sintaxes  
  para criar instruções compreensíveis por computadores.

- Essas linguagens permitem que humanos comuniquem suas intenções às máquinas,  
  possibilitando o desenvolvimento de software, como sistemas operacionais,  
  aplicativos móveis e aplicações web.

- Elas possuem semântica (significado) e sintaxe (estrutura), sendo classificadas em:
 
- **Alto nível:** Mais próximas da linguagem humana.  
- **Baixo nível:** Mais próximas do código de máquina. 
```

```
- De forma simplificada, a linguagem de programação é como nos comunicamos com o computador.
 
- Escrevemos instruções que são convertidas para código binário por um processo de "tradução",  
  chamado de **compilação** ou **interpretação**, para que possam ser executadas pela máquina. 
```
