**📖 Laços de repetição While**

```C#

Tradução "Enquanto" ou seja, enquanto uma condição for verdadeira.
```

```
Definido pela palavra while.
```

```
Exige apenas uma condição.
```

```
Checa a condição ANTES de executar.
```
```
Exemplo:
```
```C#
var valor = 0;

while (valor <= 5)
{
  Console.WriteLine(valor)
  valor++
}
```
