**Curso:** Fundamentos do C# 

A memória é dividida em duas partes Heap e Stack.

Heap armazena os dados

Stack armazena as referencias para os dados.

Qualquer tipo no .NET é tratado como tipo de referencia (Reference Type)
Tipo de valor (Value Type)

Tipos de valor armazenam dados
Sao armazenados em um local da memória chamada stack.


Quando armazena um valor do tipo value type, a mesmoria é alocada. Este espaço armazado o dado criado. NJossa variavel acessa este dado diretamente.
 Se assimilarmos uma variavel do tipo de valor a outra o valor será copiado e ambas serão indepentens.
 Built-in, Structs, Enums, Gargabe Collecto não acessa o Stack.
Exemplo:

int x = 25;
int y = x; // Y é uma cópia de X

Reference Types 

Armazena o endereço do objeto que contém os dados. Não armazena os dados em si. São armezanados em um local da memória chamado de Heap. Ao assimilar uma varivável, criará uma referência. Aponta para a mesma informação.

Quando não mais utilizados, sao marcados para exclusão. Gargave Collector passa removendo todos eles. Classes, Objects, Arrays.

var array = new string[2];
array [0] = "item 1";
var array 2 = array; // Não cria uma cópia. Cria uma referência.
