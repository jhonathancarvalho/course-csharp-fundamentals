**Curso:** Fundamentos do C# 

Usado para operações condicionais. Retorna SEMPRE verdadeiro ou falso.

E - and

Deve atender todas as Condições ==> &&
OU - or
Se atender uma condição, retorna verdadeiro ==> ||

NEGAÇÂO - not
!=

Exemplos:

int x = 12;

bool entre = 
(x >25) && (x <40);

bool ou = (x > 25 ) || (x <40)

bool negação = !(x <25)
