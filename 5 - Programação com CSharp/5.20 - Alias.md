**📖 Conceito de Alias**

```
Alias é um apelido que todo tipo no .NET tem.
```
```
Por exemplo o System.String tem o alias string.
```
```
Com alias escrevemos menos.
```
```
O CSharp é case sensitive. Ele diferencia quando escrevemos maiusculo de minusculo e o alias facilita o desenvolvimento.
```
