Outro exemplo

int  interio = 100;

float real = 25.5f;

interio = real; // ocorre um erro pois estamos tentando converter um numero real em um numero interio. Ao contrario funcionaria. 

Dessa forma ocorre a conversão implicita. 

interio = (int)real. // conversão explicita
