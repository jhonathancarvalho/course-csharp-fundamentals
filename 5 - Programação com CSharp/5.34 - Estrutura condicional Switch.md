[[5.0 - Programação com CSharp]]

**Curso:** Fundamentos do C# 

Utilizado quado temos muitas decisões

Executado em cascata

Devemos para manualmente a execução com o comando break

Possui uma execução padrão chamada default;

Exemplo:

string valor = "paulo"
switch = (valor)
{
case "joão": Console.WriteLine(Não é o cara!); break;

case "marcelo": Console.WriteLine(Não é o cara!); break;

case "andre": Console.WriteLine(Este é o cara!); break;
default: Console.WriteLine("Não encontrei!"); break;
}


Outro exemplo:

bool valor = true;
switch (valor)
{
case true: ConsoleWriteLine("Verdadeiro"); break;

case false: ConsoleWriteLine("Falso"); break;

default: ConsoleWriteLine("Nulo"); break;
}
