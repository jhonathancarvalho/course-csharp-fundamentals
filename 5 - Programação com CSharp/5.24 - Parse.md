**📖 Parse**

```
Metodo presente em todo tipo primitivo Built-in.
```

```
Usado para conversar um caractere ou string para um tipo qualquer.
```

```
Caso haja alguma incompatibilidade, gera um erro.
```

```
O Parse sempre espera uma cadeira de caractere.
```

```
Exemplo:

int interio = int.Parse("100");
```
